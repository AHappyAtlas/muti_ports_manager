# Images Directory

This directory contains images and screenshots for the README files.

## Required Images

- `screenshot.png` - Main screenshot of the Multi Ports Manager tool in action
- `demo.gif` - Demo animation showing the tool's features (optional)
- `architecture.png` - System architecture diagram (optional)

## Image Guidelines

- **Screenshot**: Should show the CLI tool in action, preferably on a dark terminal with colorful output
- **Size**: Keep images under 1MB for optimal GitHub loading
- **Format**: Use PNG for screenshots, GIF for animations
- **Resolution**: 800x600 or 1200x800 recommended for good readability

## Placeholder

1. Use a placeholder image service like [Placeholder.com](https://placeholder.com)

3. Take an actual screenshot of your tool running
